# Velvet Paws LLC - Demo Website

**Live Preview:** [Coming soon after GitHub Pages deployment]

This is a static HTML demo of the Velvet Paws LLC e-commerce website - a luxury pet supply brand with dropship pricing.

## Overview

Velvet Paws LLC is a premium pet supplies store that combines luxury aesthetics with affordable dropship pricing. This demo showcases what the final Shopify store will look like.

## Features

- **Homepage** with hero section, category cards, and featured products
- **Shop Page** with filterable product grid (15 products across 5 categories)
- **Product Detail Pages** for 3 best-selling products with full descriptions
- **About Page** explaining the brand story and philosophy
- **Contact Page** with form and business information
- **Responsive Design** that works on mobile, tablet, and desktop
- **Interactive Elements** including filtering, smooth scrolling, and cart functionality

## Design

- **Colors:** Deep purple (#6B46C1), soft lavender (#E9D5FF), gold accents (#D4AF37)
- **Typography:** Playfair Display (headings) + Open Sans (body)
- **Style:** Luxury pet brand aesthetic with velvet texture influences
- **Mobile-First:** Fully responsive across all devices

## Product Categories

1. **Dog Supplies** - Beds, toys, harnesses, feeders
2. **Cat Supplies** - Scratching posts, beds, feeders, toys
3. **Small Pets** - Hamster, rabbit, and bird supplies
4. **Health & Wellness** - Supplements, grooming, first aid
5. **Accessories** - Collars, carriers, ID tags

## Technology

- Pure HTML5, CSS3, JavaScript (no frameworks)
- Google Fonts (Playfair Display, Open Sans)
- Unsplash images for product placeholders
- Static site - no backend required

## How to Use

1. **View Locally:** Open `index.html` in any web browser
2. **Deploy to GitHub Pages:** Push to GitHub and enable Pages in repository settings
3. **Transfer to Shopify:** Use this as a design reference when building the actual store

## Next Steps for Shopify Implementation

1. Set up Shopify store and choose a theme
2. Customize theme to match this design (colors, fonts, layout)
3. Import product data from `/velvet-paws-llc/PRODUCTS.md`
4. Connect Spocket/DSers for dropshipping
5. Set up payment gateway and shipping rules
6. Configure SEO and marketing tools
